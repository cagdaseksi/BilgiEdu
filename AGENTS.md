# BilgiEdu workshop rules

- Use ASCII characters in source, filenames, UI text and documentation.
- Each participant works in their own local clone and branch participant/<slug>.
- Participant agents may edit only src/participants/<assigned-slug>/**.
- Read AGENTS.md inside your assigned participant directory before editing.
- Do not edit another participant, shared UI, routing, generated files, native projects, dependencies, ownership roster, scripts or workflows.
- Never push directly to main or merge a PR. Submit your branch for maintainer review.
- Import local modules or src/shared; never import another participant's code.
- Stop timers, audio, animations and subscriptions in effect cleanup.
- The maintainer adds participants and manages GitHub login ownership.
- Run npm run check before submitting. The participant registry is generated automatically.
- Keep credentials, signing keys, tester emails and release artifacts out of Git.
